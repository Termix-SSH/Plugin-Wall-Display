<h1>Wall Display</h1>

<p>A full screen Termix layout for a TV or spare monitor that cycles through your status views</p>

</div>

<br />

## Overview

Wall Display turns Termix into a status board. There is no sidebar, no tab bar and nothing to edit. It shows Homepage, Uptime, Host Status and Network Topology full screen, one after another, and skips any whose plugin is not installed.

Sign in on the screen as a read only user and pick Wall Display in Settings, Appearance.

Read the [docs](https://docs.termix.site/plugins/wall-display) to learn how it works.

<br />

## Features

- Full screen with no sidebar, tab bar or editing
- Cycles through Homepage, Uptime, Host Status and Network Topology
- Skips views whose plugin is not installed
- Big host status board with online and offline counts
- Pause, next and previous from the keyboard or a hidden toolbar
- Keeps the screen awake and hides the cursor
